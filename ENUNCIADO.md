# Enunciado resumido

Construye un gestor de expedientes que lea y escriba `data/expedientes.json`.

El programa debe permitir:

1. Listar todos los expedientes.
2. Buscar uno por ID.
3. Filtrar por prioridad o estado.
4. Crear uno nuevo con datos válidos.
5. Actualizar el estado de uno existente.
6. Guardar los cambios.

Usa funciones, tipos, excepciones concretas y Git. Consulta el README para los requisitos completos.
